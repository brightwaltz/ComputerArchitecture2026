最低限 1

記憶する回路：たすき掛けで1ビットを覚える

授業スライド 18〜21

順序回路は記憶（メモリ）を持ち、出力がいまの入力と前の入力の両方で決まる。記憶のもとは、2つのインバータを輪にした「たすき掛け」の回路で、Q=0 でも Q=1 でも安定する（双安定）。順序回路の出力は Q と書く。

最低限 2

RS ラッチ：S で 1 に、R で 0 に、戻しても覚えている

授業スライド 21〜23

RS ラッチは、S（Set）を 1 にすると Q が 1 に、R（Reset）を 1 にすると Q が 0 になる。入力を 0 に戻しても、Q は変わらずに覚えている。S と R を同時に 1 にするのは使わない約束（禁止）。

確認問題は、NAND をたすき掛けにしたラッチです。入力に上線が付いた S・R は「0 にすると働く」入力です。授業の RS ラッチと同じ考え方で、表を自分で埋めてみましょう。

最低限 3

D ラッチ：CLK が 1 の間だけ D が通り抜ける

授業スライド 24〜26

D ラッチは、CLK が 1 の間は D の値がそのまま Q まで通り抜ける（透過）。CLK が 0 になると通り道が閉じ、Q は閉じる直前の値のままになる（不透明）。D ラッチには禁止の入力はない。

最低限 4

D フリップフロップ：立ち上がりの瞬間だけ D を写す

授業スライド 27〜28

D フリップフロップ（D-FF）は、CLK が 0 から 1 に変わる瞬間（立ち上がり）の D だけを Q に写し、それ以外のときは Q を保持する。中は D ラッチ2つで、反転した CLK で動く前のラッチをマスタ、CLK で動く後ろのラッチをスレイブと呼ぶ。

最低限 5

タイミングチャート：Q と Q を描く

授業スライド 29

立ち上がりごとに縦線を引き、その瞬間の D を読む。Q は次の立ち上がりまでその値のまま。Q は Q を上下反対にしたもの。最初の立ち上がりまでは、Q は初めの値のまま。

最低限 6

レジスタとカウンタ：D-FF を並べる・つなぐ

授業スライド 31〜35

レジスタは、CLK を共通にした D-FF の集まりで、全ビットが同じ立ち上がりで一度に書きかわる。カウンタは、D-FF の Q を自分の D に戻して立ち上がりのたびに反転させ、その出力を次の D-FF の CLK につないで、クロックの数を2進数で数える。

つまずきやすいところ

  • ラッチと FF は違う：D ラッチは CLK=1 の「間ずっと」D に従い、D-FF は立ち上がりの「瞬間」だけ D を読みます。CLK=1 の途中で D が変わると、2つの Q は違う形になります。
  • 立ち下がりでは変わらない：授業の D-FF は立ち上がりエッジ型です。CLK が 1 から 0 に変わるときには、Q は変わりません。
  • Q も描く：タイミングチャートでは Q と Q の両方を描きます。Q はいつも Q の反対です。
  • 最初の立ち上がりの前：最初の立ち上がりまでは、Q は問題で決めた初めの値のままです。
  • 禁止のあと：RS ラッチで S と R を同時に 1 にしたあと、両方を同時に 0 に戻すと、Q が 0 と 1 のどちらになるか決まりません。だから禁止にします。
  • カウンタの向き：授業の立ち上がり型 D-FF で上へ数える（1ずつ増える）には、次の D-FF の CLK に Q をつなぎます。Q をつなぐと下へ数えます。項目6の模型で確かめましょう。
  • SimcirJS の D-FF 部品は立ち下がりで動く：SimcirJS のパーツリストにある D-FF は、CLK が 1 から 0 に変わる瞬間に D を写します（授業とテストの D-FF は立ち上がり型）。部品の動きを確かめるときは、どちらの向きで変わるかに気をつけましょう。この部品でカウンタを作るときは、Q を次の CLK につなぐと上へ数えます。
