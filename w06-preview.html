第6回 予習順序回路（11/19 の授業の前に。11/5・11/12 は休講）

第5回までの回路は、いまの入力だけで出力が決まる「組み合わせ回路」でした。第6回は、0 と 1 を覚えておける「順序回路」を学びます。授業の前に、このページの3つをやっておきましょう。

第6回も PC を持ってきてください（SimcirJS で演習をします）。

目安 20〜25分（動画 約1分15秒を含む）書き込んだ内容はこのブラウザの中だけに残ります
動画を見る：記憶する回路（たすき掛けのインバータ、約1分15秒）

    今日の問い：回路は、どうやって 0 と 1 を覚えておくのか？

    インバータ（NOT）2つだけで、1ビットを覚える回路ができます。途中で止まったら、予想を選んでから続きを見てください。

    答えは1〜2行のメモで十分です。3つ以上に書き込むと、上のランプ 1 が点きます。

    前回の確認（3問）

    第5回 論理回路と組み合わせ回路

    解けなかったら、第5回 復習ページで確かめてから授業に来てください。

    やること 3

    ゲーム：波形を読む

    授業スライド 29〜35 のタイミングチャートにつながります

    横軸が時間、縦が 0 と 1 の図（タイミングチャート）を読む練習です。6問を解き終えると、ランプ 3 が点きます。

    授業の前に知っておくと楽になること

    • クロック（CLK）は、0 と 1 を一定の間隔でくり返す信号です。回路はクロックに合わせて動きます。
    • 立ち上がりは 0 から 1 に変わる瞬間、立ち下がりは 1 から 0 に変わる瞬間です。
    • 順序回路の出力は、組み合わせ回路の Y と区別して Q と書くことが多いです。
