# コンピュータアーキテクチャ 2026 予習・復習ページ

玉川大学 工学部 ソフトウェアサイエンス学科「コンピュータアーキテクチャ」（2026年度 秋・木曜3・4限）の予習・復習ページです。

このリポジトリは Claude Code（Anthropic）を使って作っています。

公開ページ：https://brightwaltz.github.io/ComputerArchitecture2026/

- 予習ページは授業の1週間前、復習ページは授業の日に公開します。
- 解いた結果やメモは、使っているブラウザの中（localStorage）だけに保存されます。外部へは送られません。
- 練習問題は練習用に作ったもので、テストの問題そのものではありません。

このリポジトリには、組み立て済みのページだけを置いています（1ページ＝HTML 1ファイル、外部のスクリプトなし）。
